# Templates

Worked examples to copy when authoring a note: a need, a requirement addressing it, and a decision satisfying the requirement.
They show the envelope, the four required fields, the unheaded lead, and `## Relations` citations, in the smallest form that carries the intent.

Placeholder conventions:

- The namespace `garden` and every id here are placeholders.
  After copying, replace the namespace with the target corpus's own and mint a fresh opaque with `scripts/mint.py`; never reuse a template's id.
- Keep a section only where it carries substance; delete the rest rather than fill it.
- Validate the result with `scripts/validate.py` before committing.
